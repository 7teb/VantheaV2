# VantheaX

VantheaX is a local coding agent for Windows. It is an Electron desktop app: the main process owns all state (chats, settings, agents, skills) and the window is the view. Models are reached through OpenRouter (API pricing), for the OpenAI models the signed-in ChatGPT plan offers through that plan, and for the Claude models through the Claude plan, which runs them in Claude Code with the user's own Claude subscription; every other model still goes through OpenRouter, and both plans can be on at the same time (Settings > General > Billing). The agent works on the open project folder with file tools, runs PowerShell through run_command and, when Git for Windows is installed, Git Bash through run_bash, can drive an in-app browser, deploy sub-agents and start background tasks.
